# Shield Construction &amp; Contracting

Static marketing site for Shield Construction &amp; Contracting, a Saudi construction and contracting house headquartered in Al Jubail. Building the Kingdom's future, aligned with Vision 2030.

## Structure

```
shield/
├── index.html              # Single-page site
├── assets/
│   ├── styles.css          # Compiled stylesheet (Tailwind)
│   ├── hero-construction.jpg
│   ├── industrial.jpg
│   ├── team.jpg
│   ├── infrastructure.jpg
│   └── images/
│       ├── shield-logo.png
│       └── nasir-hussain.png
└── README.md
```

## Run locally

It is a fully static site, so any static file server works:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just open `index.html` directly in a browser.

## Deploy

The site is static and can be hosted on GitHub Pages, Netlify, Vercel, or any static host. For GitHub Pages, enable Pages on the repository and point it at the root of the default branch.
